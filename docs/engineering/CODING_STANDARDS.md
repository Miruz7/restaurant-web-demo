# Coding Standards

## React

Componentes funcionales.

Hooks.

No clases.

---

## TypeScript

Nunca usar any.

Siempre tipar Props.

Siempre tipar funciones.

Usar interfaces.

---

## Código

Funciones pequeñas.

Nombres descriptivos.

No duplicar código.

No comentarios innecesarios.

Código autoexplicativo.

---

## Archivos

PascalCase para componentes.

camelCase para funciones.

kebab-case para assets.
