# Papelería Nova

## Visión del Proyecto

Papelería Nova es una Landing Page premium desarrollada como demostración profesional de desarrollo Frontend.

No representa una papelería real.

El objetivo es demostrar habilidades avanzadas en:

- React
- TypeScript
- Tailwind CSS
- GSAP
- Lenis
- Framer Motion
- Optimización Web
- Arquitectura Frontend

---

## Inspiración

La experiencia visual está inspirada en sitios de alta calidad como:

- Apple
- Awwwards
- Azur Promilia

El diseño será completamente original.

Nunca se copiará código, imágenes o contenido.

---

## Objetivos

Crear una experiencia cinematográfica.

Demostrar dominio técnico.

Mantener una arquitectura escalable.

Construir una plantilla reutilizable para futuros clientes.

Obtener un Lighthouse superior a 95.
