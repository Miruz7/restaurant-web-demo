## Objetivo

Crear la implementación base de los Design Tokens utilizando CSS Custom Properties.

## Alcance

Implementar únicamente:

- colors.css
- typography.css
- spacing.css
- radius.css

## Requisitos

- Utilizar `:root` para declarar las variables.
- No crear clases CSS.
- No modificar componentes React.
- No crear utilidades de Tailwind.
- Mantener una nomenclatura consistente (`--color-*`, `--space-*`, `--radius-*`, etc.).
- No inventar nuevos colores fuera del Design System.

## Resultado esperado

1. Explicar qué archivos fueron modificados.
2. Mostrar las variables creadas.
3. Justificar cualquier decisión que no estuviera documentada.
4. Esperar revisión antes de continuar.
