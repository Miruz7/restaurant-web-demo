# VA-1 — First Impression

## Observaciones

- Existe un único protagonista visual por pantalla.
- El fondo apoya al contenido principal y no compite con él.
- La jerarquía visual es muy clara.
- El CTA aparece pronto y es fácil de identificar.
- El cambio entre módulos se percibe como una transición narrativa, no como un simple scroll.

## Principios extraídos

1. Cada pantalla debe tener un único punto focal.
2. La jerarquía visual debe guiar la mirada sin esfuerzo.
3. El contenido secundario nunca debe competir con el principal.
4. Las transiciones entre secciones deben reforzar la sensación de continuidad.
5. La primera impresión debe sentirse deliberada y cuidada.

## Principios de composición

1. La retícula permanece constante entre módulos.
2. El espacio en blanco es un elemento de diseño, no un espacio sin usar.
3. La imagen aporta presencia; el texto aporta contexto.
4. La interacción aparece antes del contenido principal.
5. Las transiciones modifican el contenido, no la estructura.
6. La profundidad se construye con capas.
7. La consistencia incluye tanto la apariencia como el comportamiento.
8. Los módulos complejos pueden contener sistemas de navegación internos sin alterar la navegación global.
