# Arquitectura

La arquitectura sigue principios de Clean Architecture adaptados al Frontend.

## Reglas

Cada carpeta tiene una responsabilidad.

No duplicar componentes.

Separar lógica y presentación.

Usar componentes reutilizables.

No escribir lógica compleja dentro del JSX.

No crear componentes gigantes.

Cada sección importante tendrá su propia carpeta.

Mantener imports ordenados.
